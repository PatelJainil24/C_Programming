11. Explain the function of the TCP/IP model and its layers.
-> 1.Application Layer
    - Client: Web browser, email client, etc.
    - Server: Web server, email server, etc.
    - Handles: HTTP, FTP, DNS, SMTP, etc.

    2. Transport Layer
        - Client & Server: Ensures reliable data delivery.
        - Protocols: TCP (reliable), UDP (faster, less reliable).
        - Breaks data into segments and reassembles it.
    3. Internet Layer
        - Client & Server: Manages logical addressing and routing.
        - Protocol: IP (Internet Protocol).
        - Sends packets across networks.
    4. Network Access (Link) Layer
        - Client & Server: Interfaces with physical network (like Ethernet/Wi-Fi).
        - Handles: MAC addresses, switches, physical transmission.

32. What types of software maintenance are there?
-> Software maintenance involves updating and improving software after it has been released. There are four main types:

    1. Corrective Maintenance
        Purpose: Fix bugs or errors found after release
        Example: Resolving a crash when a user clicks a button

    2. Adaptive Maintenance
        Purpose: Modify the software to work in a new environment (e.g., OS updates, hardware changes)
        Example: Updating software to support a new version of Windows
    3. Perfective Maintenance
        Purpose: Improve performance, readability, or add new features
        Example: Enhancing UI design or adding a search feature

    4. Preventive Maintenance
        Purpose: Make changes to prevent future issues or improve maintainability
        Example: Code refactoring or cleaning up unused functions
